Google-klon: Det här är alltså en ganska enkel version av Googles startsida, byggd med HTML och CSS. Jag har gjort en toppmeny med några länkar, lagt in en Google-logga, en sökruta, knappar för sökning och en footer med olika länkar längst ner. Layouten är fixad med Flexbox, så att allt hamnar ungefär där det ska vara. Sidan funkar också på både dator och mindre skärmar eftersom den är responsiv, alltså anpassar sig efter skärmstorleken. Poängen med projektet var mest att öva på grunderna i webbutveckling och förstå hur HTML och CSS hänger ihop när man bygger moderna sajter.

Funktioner:
En toppmeny med länkar, logga in-knapp, google-logga, sökruta där man kan skriva, knapparna ”Sök på Google” och ”Jag har tur”, footer med diverse länkar, flexbox för layouten, hover-effekter på länkar och knappar, media queries för att göra sidan responsiv

Det som var lätt:
Att sätta ihop den grundläggande HTML-strukturen gick ganska smidigt. Jag hade ju fusklappar som visade hur man använder de där element som header, main och footer, så det var inte så krångligt. Att lägga till länkar och knappar gick också utan större problem, eftersom de är ganska standard i HTML och jag hade jobbat med dem förut. När själva strukturen var på plats var det faktiskt inte så svårt att använda Flexbox för att ordna saker på rätt ställe. Med hjälp av display:flex, justify-content och align-items kunde jag centrera grejer och få menyerna att sitta där de skulle.

Det som var klurigt:
Det svåraste var att få sidan att verkligen likna Googles startsida. Jag fick pilla mycket med färger, storlekar, marginaler och avstånd flera gånger för att det skulle se någorlunda rätt ut. Speciellt sökrutan var en utmaning. Den var ju tvungen att ha exakt rätt storlek, rundade hörn och passa in snyggt med resten av designen.

En annan grej som ställde till det var att förstå hur olika CSS-regler påverkar varandra. Jag kunde ändra en liten sak och plötsligt så påverkade det flera andra delar på sidan, ibland på oväntade sätt. För att hålla koll behövde jag testa mig fram och skriva kommentarer i koden så jag inte skulle tappa bort mig. När jag fastnade använde jag även AI och videoguider för att få hjälp att förstå vissa CSS-regler och hitta lösningar på problem i layouten.

Responsiv design var också ett huvudbry. Media queries krävde att jag funderade på hur olika element beter sig på olika skärmstorlekar och hur Flexbox kan anpassa sig för mobiler och surfplattor. Även här använde jag ibland AI och videor för att få en bättre förståelse för hur man bygger en responsiv webbplats. Det tog ett tag innan jag fick kläm på det.

Vad jag lärde mig: 
Under den här tiden har jag blivit duktigare på att använda HTML5-element som header, main och footer. Jag har också förstått vikten av att jobba med CSS-klasser och ID:n för att styra utseendet på olika delar av sidan. Flexbox är numera inte så mystiskt längre, och jag kan använda det för att skapa smarta layouter. Dessutom har jag fått kläm på hur man använder pseudoklasser som hover för att göra länkar och knappar mer levande, plus media queries för att göra sidan smartare på olika skärmar. Jag har dessutom börjat strukturera min kod bättre och skriva kommentarer. Det gör livet så mycket lättare när man ska tillbaka och fixa något senare.

Sammanfattning:
Sammanfattningsvis har projektet gett mig en bättre bild av hur HTML och CSS funkar tillsammans och hur små ändringar i koden kan göra ganska stor skillnad i hur sidan ser ut och fungerar.
